      May 17th, 2011

    1. Response from developer, needed to check out latest copy of spl to build against. Did so, and working build now.
    2. Default kernel installed after PREEMPT issue found above, sources not installed, need to install specific devel package: {syntaxhighlighter brush:bash;} zypper in kernel-default-devel 2.6.34.8-0.2 {/syntaxhighlighter}
    3. Install of libraries went to /usr/local/lib, need to add that to ld.so.conf so that other programs pick them up.
